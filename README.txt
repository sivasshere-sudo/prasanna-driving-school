PRASANNA DRIVING SCHOOL — LOGO INTEGRATION

1. Upload your image file named exactly:
   prasanna_driving_school_logo.jpg

2. Put the image in this folder in your repository:
   assets/images/prasanna_driving_school_logo.jpg

3. Copy the contents of logo-snippet.html into the <header> of
   index.html, about.html, and contact.html (where you want the logo).

4. Add the contents of logo.css to your existing style.css.

Important: Uploading an image or this ZIP alone does not automatically
change existing webpages. The HTML must contain the image reference.
